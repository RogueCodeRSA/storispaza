# Contributing

Read AGENTS.md, docs/SPEC.md and docs/PLAN.md. Use Node 24 and npm ci. Run npm run check; install Playwright Chromium then npm run test:e2e. No key needed for default tests.

Stay within approved milestone, add meaningful behavioral tests, review full diff and update evidence/docs. Never commit keys, private stories/audio or data/. Public fixture audio requires redistribution consent. Preserve creator edits, provenance and review labels. Language output alone never establishes authentic support.

Use skills/language-pack and docs/ADDING_A_LANGUAGE.md for languages. Disable unreviewed speech capabilities. Report security issues without personal data/credentials. Public hosting/new integrations need separate design; current app is local-only.
